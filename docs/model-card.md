# 모델 카드

## 한 줄 요약

이번 화면 변경은 기존 로그인 화면과 헤더의 로그아웃을 실제 백엔드 인증 API에 연결한다. 모델 기능은 변경하지 않는다.

## 문제 유형 (분류 / 회귀 / 군집 / 추천)

미정

## 입력 (X)

모델 입력은 미정. 로그인 화면은 로그인 아이디와 비밀번호를 받는다.

## 출력 (y)

모델 출력은 미정. 로그인 성공 시 홈으로 이동하고 헤더에 로그인 아이디를 표시한다. 실패 시 오류 메시지를 표시한다.

## 결과 근거

모델 결과 근거는 미정. 로그인 여부는 백엔드 인증 응답을 기준으로 한다.

## API 초안

- 로그인: POST /api/v1/auth/sessions
- 로그아웃: DELETE /api/v1/auth/sessions/current
- 상세 요청·응답은 api-draft.md 참조.

## 미결정 사항

- 자동 로그인·토큰 만료 후 화면 갱신은 이번 연결 범위에 포함하지 않는다.
- 회원가입·아이디 찾기·비밀번호 재설정·다른 화면의 mock 데이터는 이번 변경 범위에 포함하지 않는다.
