# 회원 생년월일 컬럼 제거

회원가입 입력·요청·응답 DTO와 회원 조회·저장·수정 SQL에서 생년월일을 제거했다.
이 문서의 SQL은 자동 실행되지 않는다.
다른 미사용 테이블까지 함께 정리하려면 [미사용 DB 정리](db-cleanup.md)를 따른다. 생년월일 컬럼 삭제는 중복 실행하지 않는다.

## 적용 순서

1. 대상 DB와 `users` 테이블의 정의를 확인하고 기존 데이터가 필요하면 백업한다.
2. 생년월일을 참조하지 않는 새 백엔드와 프론트엔드를 적용한다. 기존 컬럼이 남아 있어도 조회·수정에서 사용하지 않는다. 가입은 기존 컬럼이 NULL 또는 기본값을 허용하는지 확인한다.
3. 이전 버전 서버가 더 이상 실행되지 않는지 확인한 뒤 아래 ALTER를 실행한다. 컬럼을 삭제하면 저장된 생년월일도 삭제된다.

```sql
SELECT DATABASE();
SHOW CREATE TABLE `users`;

ALTER TABLE `users` DROP COLUMN `BIRTH_DATE`;
```

## 적용 후 확인

- 회원가입이 성공하고 로그인 및 회원정보 조회·수정이 정상 동작하는지 확인한다.
- 가입 요청과 `/api/v1/users/me` 응답에 생년월일 필드가 없는지 확인한다.
- 회원 조회·가입·수정 로그에 삭제한 컬럼 참조가 없는지 확인한다.
