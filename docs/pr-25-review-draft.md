## 1. PDF 원본과 백엔드 응답 비교 결과 작성

Python 응답과 Java DTO의 전달 구조는 연결되어 있습니다. 다만 현재 PR의 실행 확인 항목이 모두 미체크 상태라 실제 추출 정확성을 확인하기 어렵습니다.

- 텍스트 PDF와 스캔 PDF 각각의 실행 결과를 작성해 주세요.
- 원본의 거래 날짜·구분·세전 금액·차감 세금·실입금액이 API 응답과 일치하는지 확인해 주세요.
- 인식에 실패한 거래는 성공한 것으로 처리하지 않고, 실패 여부와 이유가 전달되는지 확인해 주세요.
- 확인하지 못한 항목은 미확인으로 표시해 주세요.

## 2. 게시판 변경 분리 및 인증 담당자와 조율

PDF 기능과 별개로 PostValidator, PostApiController, PostServiceImpl, PostMapper.xml 및 청크 업로드 코드가 크게 변경되어 있습니다.

이번 PR에서는 게시판 변경을 분리해 주세요. 필요한 변경이라면 목적과 영향 범위를 별도 PR에 설명하고, 인증·인가 관련 부분은 기존 담당자와 조율해 주세요.

참고로 PostValidator는 JWT를 다시 검증하는 것이 아니라 SecurityContext에 설정된 인증 정보를 사용하고 있습니다. 따라서 로그인·작성자·관리자 권한 검사를 일괄 삭제하자는 요청은 아닙니다.

## 3. requirements.txt 의존성 정리

기존 공용 라이브러리 목록과 버전 고정은 유지하고, 이번 PDF 기능에 필요한 패키지와 그 하위 의존성만 추가해 주세요.

추가된 TensorFlow·Keras·Jupyter 관련 패키지·Playwright·Matplotlib·Seaborn·SQLAlchemy·PyMySQL 등은 현재 PDF 코드에서 필요한 이유가 확인되지 않습니다. 사용 위치와 필요성을 확인하고 불필요한 추가 항목은 제외해 주세요.

개인 개발 환경 전체의 패키지 목록보다 서비스 실행에 필요한 의존성을 기준으로 정리하고, 정리한 목록으로 새 가상환경에서 설치·서버 기동·PDF 분석이 되는지 확인해 주세요.
