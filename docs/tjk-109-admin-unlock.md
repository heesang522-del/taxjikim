# TJK-109 관리자 계정 잠금 해제

- 관리자 회원 관리에서 실제 `BANNED`·`LOCKED` 계정만 표시한다.
- 아이디·상태·상태 변경 시각·해제를 같은 너비로 표시한다. 시각은 `UPDATED_AT`을 한국 시간으로 표시한다.
- 해제하면 `ACTIVE`로 변경하고 `UPDATED_AT`을 갱신하며, 기존 로그인 세션과 실패 기록을 삭제한다.
- 조회·해제 API는 서버에서 `ADMIN` 권한을 검사한다.
- 기존 실패 정책·기록 저장소와 이메일 해제 기능은 변경하지 않는다.

## API

- GET `/api/v1/admin/account-locks`: 제한 계정 목록, 최대 100개.
- DELETE `/api/v1/admin/account-locks/{loginId}`: 제한 해제.

## 확인

- 사용자가 실제 화면에서 두 상태의 해제·목록 제거·재로그인 성공을 확인했다.
- 분리한 PR 브랜치에서도 관리자 권한 및 서비스 테스트, 프론트 빌드를 실행한다.
- 로컬 테스트 소스는 저장소의 기존 ignore 규칙에 따라 커밋하지 않는다.
