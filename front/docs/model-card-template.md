# 모델 카드 작성 양식

front/AGENTS.md에서 옮긴 기존 양식이다. 모델 카드를 작성·갱신할 때만 읽고, 확정된 내용만 기록하며 나머지는 `미정`으로 둔다. 기존 모델 카드를 이 빈 양식으로 덮어쓰지 않는다.

~~~markdown
# 모델 카드

## 한 줄 요약

## 문제 유형 (분류 / 회귀 / 군집 / 추천)

## 입력 (X)
| 항목 | 타입 | 예시 | 입력 위치 |

## 출력 (y)
| 항목 | 타입 | 예시 | 표시 위치 |

## 결과 근거

## 학습 데이터 후보

## 평가 지표 후보

## API 초안

## 미결정 사항
~~~
