## 백엔드 예상세액 계산에 사용한 값

확인일: 2026-11-03. 대상 코드: `back/src/main/java/com/kh/back/tax/dto/TaxBreakdownDto.java`.
아래는 실제 구현값과 근거를 기록한 것으로, 모든 적용 요건·부칙·과거 귀속연도별 계산까지 검증했다는 의미는 아니다.

| 항목 | 사용한 값 | 확인할 출처 |
| --- | --- | --- |
| 기본공제 | 본인 포함 대상자 1명당 연 1,500,000원. 코드: `(본인 1 + dependentCount) × 1,500,000` | [소득세법 제50조](https://www.law.go.kr/법령/소득세법/제50조), [2026-07-01 시행 소득세법](https://www.law.go.kr/LSW/lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=20260701&lsiSeq=280405). 가족별 소득·나이 등 기본공제 요건 충족을 전제로 하며 인원수만으로 자격을 자동 판정하지 않음 |
| 표준세액공제 | 일반 사업소득자 기준 연 70,000원, 산출세액 한도 내 적용. 법정 성실사업자 120,000원은 현재 계산에 미반영 | [소득세법 제59조의4 제9항 제2호](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1033240537). 근로소득이 없고 관련 세액공제를 신청하지 않은 경우 등 요건 확인. 2026-07-01 시행 조문에서 7만원·12만원 구분 확인 |
| 종합소득세 과세표준 구간 | 14,000,000 / 50,000,000 / 88,000,000 / 150,000,000 / 300,000,000 / 500,000,000 / 1,000,000,000원 이하 및 1,000,000,000원 초과 | [소득세법 제55조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1032882459), [국세청 세율표](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7667&mi=2224). 국세청 표는 2023~2025년 귀속으로 표시되어 있으므로 2026년 적용은 법령 시행일·부칙과 함께 확인 |
| 종합소득세 세율 | 위 구간 순서대로 6 / 15 / 24 / 35 / 38 / 40 / 42 / 45% | [소득세법 제55조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1032882459), [국세청 세율표](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7667&mi=2224). 코드의 세율 목록과 안내 표 일치 확인. 연도별 세율 선택은 미구현 |
| 누진공제액 | 위 구간 순서대로 0 / 1,260,000 / 5,760,000 / 15,440,000 / 19,940,000 / 25,940,000 / 35,940,000 / 65,940,000원 | [국세청 세율표](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7667&mi=2224). `과세표준 × 세율 − 누진공제액` 방식의 값으로 코드와 표 일치 확인. 2026년 적용 세율에 따른 누진 계산과의 대조는 추가 확인 대상 |
| 종교단체 외 일반기부금 필요경비 한도 | `(기준소득금액 − 특례기부금 인정액) × 30%`. 이월결손금·이월기부금은 현재 계산하지 않음 | [소득세법 제34조 제3항 제2호 나목](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1032008575). 2026-07-01 시행 조문에서 종교단체 기부가 없는 경우의 30% 확인. 기부금 자체의 30%를 세액공제하는 의미가 아님 |
