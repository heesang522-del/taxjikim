## 한 줄 요약
미정
## 문제 유형 (분류 / 회귀 / 군집 / 추천)
미정
## 입력 (X)
| 항목 | 타입 | 예시 | 입력 위치 |
| --- | --- | --- | --- |
| 나이 | 숫자 | 32 | 세금 계산 > 입력 (현재 계산에 미반영, 사용 여부 미정) |
| 지역 | 선택 | 서울특별시 | 세금 계산 > 입력 (현재 계산에 미반영, 사용 여부 미정) |
| 직군 | 선택 | 개발자 (소프트웨어) | 세금 계산 > 입력 (현재 계산에 미반영, 사용 여부 미정) |
| 거래 내역 (구분, 날짜, 내용, 카테고리, 금액) | 표 | 수입 / 2026-03-01 / 외주 용역비 / 5,000,000 | 세금 계산 > 입력 |
## 출력 (y)
| 항목 | 타입 | 예시 | 표시 위치 |
| --- | --- | --- | --- |
| 예상 세액 (종합소득세 + 지방소득세) | 숫자 | 2,211,000원 | 세금 계산 > 결과 |
| 월별 수입·지출 | 목록 | 2026-03 / 6,100,000 / 3,800,000 | 세금 계산 > 결과 (차트) |
## 결과 근거
수입 − 지출 = 과세표준(단순 추정), 세율표(`utils/tax.js`) 적용, 지방소득세 10% 가산, 원천징수 3.3% 차감
