# CLAUDE.md

## Project
- 금융 데이터 분석·ML 서비스의 프론트엔드 프로토타입. 목적은 핵심 흐름(입력 → 모델 결과 → 근거 → 사용자 행동) 검증.
- 백엔드, 모델 서버, DB 없음. 모든 데이터와 예측 결과는 mock.
- 사용자는 React 입문 수준. 생성한 코드는 사용자가 읽고 설명할 수 있어야 한다.

## Stack
- Vite + React, JavaScript(.jsx)만 사용
- react-router-dom, zustand(+persist), styled-components, recharts(차트 전용)
- 금지: TypeScript, Tailwind·CSS 프레임워크, UI 라이브러리(MUI, antd 등), Redux, Context API 기반 전역 상태, Next.js, axios
- 목록에 없는 패키지는 설치 전 사용자 승인 필요

## Scope
구현 순서:
1. 입력 화면: 모델 입력값을 받는 폼
2. 결과 화면: 결과값, 결과 근거, recharts 시각화 1개 이상, 사용자의 다음 행동
3. (선택) 관리자 화면: 모델 성능 지표, 데이터 현황

구현하지 않음: 로그인·회원가입·마이페이지, 게시판·댓글·Q&A·알림·채팅, 파일 업로드 처리, 결제, 애니메이션·반응형 세부 조정.
요청받으면 범위 밖임을 알리고 진행 여부를 확인한다. 공통 레이아웃은 최소한으로.

## Before coding
아래가 정해지지 않았으면 코드 작성 전에 사용자에게 질문한다. 임의로 정하지 않는다.
- 입력 항목 (이름, 타입, 범위)
- 출력 항목 (숫자 / 등급 / 목록 / 확률)
- 결과 근거로 보여줄 것
- 결과를 본 사용자의 다음 행동

사용자가 위임하면 선택지 2~3개를 제시하고 고르게 한다.

## Structure
~~~
src/
  mocks/       # mock JSON
  api/         # 데이터 접근 함수. 화면은 여기만 호출
  store/       # zustand
  pages/
  components/
docs/
  api-draft.md   # 요청/응답 JSON 예시
  model-card.md  # 모델 입력/출력 초안
  to-verify.md   # 사실 확인 필요 항목
~~~
폴더 구조를 임의로 변경하지 않는다.

## Mock data
- 컴포넌트에서 mock JSON을 직접 import하지 않는다. `src/api/*.js`를 거친다.
- api 함수는 async, 300~800ms 지연 포함. 실제 API로 교체 가능한 시그니처를 유지한다.
- mock 예측은 단순 규칙 함수로 구현하고 `// MOCK:` 주석을 단다.
- mock 결과를 표시하는 UI에 "예시 데이터" 배지를 붙인다.
- 로딩, 빈 결과, 잘못된 입력 상태를 처리한다.
- api 함수를 추가·변경하면 `docs/api-draft.md`를 갱신한다.

## Financial facts
- 세율, 공제 한도, 금리, 대출 자격요건, 신용점수 기준 등 실제 수치를 지어내지 않는다.
- 예시 수치는 코드와 UI에 "예시값"으로 표시하고 `docs/to-verify.md`에 `항목 / 사용한 값 / 확인할 출처` 형식으로 기록한다.
- 불확실한 내용은 불확실하다고 말한다.

## Privacy
- mock 데이터에 실제 개인정보를 쓰지 않는다.
- 이름·계좌번호 등은 마스킹해서 표시한다. (예: `홍*동`, `123-****-7890`)

## Working rules
- 한 번에 한 화면 또는 한 컴포넌트만 변경한다. 큰 요청은 단계로 나누자고 제안한다.
- 작업 전: 계획을 3줄 이내로 제시.
- 작업 후: 변경 파일 목록, 브라우저에서 확인하는 방법.
- 상태 변경, 데이터 흐름, 계산 로직에는 한국어 주석으로 의도를 적는다.
- 설명 요청에는 코드를 수정하지 않고 설명만 한다.
- 기존 동작을 깨뜨리지 않는다. 다른 파일을 크게 수정해야 하면 먼저 알린다.
