# 초기 CSV와 사용자 추가 CSV로 재학습하기

지출 모델용 실행 구조다. 수입 모델·DB 후보 수집·CSV 내보내기는 아직 연결하지 않았다.
기존 PDF API와 `models/expense_classifier`는 그대로 유지한다.

## 보관 구조

```text
data/expense/category_dummy_v4_draft/  초기 원본과 고정 train_test
data/expense/user_approved/           검토한 추가 CSV를 누적 보관
models/expense_retraining/실행시각/   실행별 dataset, model, run_manifest.json
```

추가 CSV는 기존 파일을 덮어쓰지 말고 날짜·배치별 새 이름으로 넣는다.
매 실행은 초기 train과 추가 CSV 전체를 합쳐 처음부터 학습한다. 이전 모델에 이어 학습하는 방식이 아니다.
초기 자료 365건 중 시험 73건은 계속 시험용으로 보존하고 학습에 넣지 않는다.
초기 자료의 PENDING 상태는 그대로 유지한다. 추가 자료만 사람이 검토한 APPROVED를 받는다.

## 추가 CSV 형식

UTF-8 CSV에 다음 헤더가 필요하다. 아래 행은 형식 설명용 가상 자료다.

```csv
sample_id,description,category_code,group_id,review_status
user_batch01_001,영상 자막 편집 외주 작업비,OUTSOURCING,user_editing_group01,APPROVED
```

- sample_id: 전체 배치에서 겹치지 않는 후보 번호. 이미 사용한 번호로 내용을 바꾸지 않는다.
- description: 개인정보를 제거한 거래 설명. 실제 설명에 없는 업무 목적을 덧붙이지 않는다.
- category_code: 초기 지출 학습자료에서 지원하는 영문 정답 코드.
- group_id: 같은 문장 틀·유사 거래는 같은 그룹을 유지한다. 초기 시험 그룹과 겹치면 안 된다.
- review_status: 사람이 설명과 정답을 검토한 APPROVED만 넣는다.

자동 추천 유지·미분류 건너뛰기·수입·UNCLASSIFIED는 추가 학습 정답으로 넣지 않는다.
사용자가 지정했더라도 설명만으로 구분할 수 없는 거래는 승인하지 않는다.
승인 전 후보는 이 폴더 밖의 별도 DB/보관소에서 관리한다. 이 명령은 CSV를 수집하거나 승인하지 않는다.
CSV를 작성 중일 때 읽히지 않도록 .tmp 파일로 완성한 뒤 .csv 이름으로 바꿔 넣는다.

## 미분류 거래와 학습 후보

미분류 거래도 서비스 거래 내역에는 저장하는 방향이다. UNCLASSIFIED 자체를 정답으로 재학습하지 않는다.

```text
미분류 거래 저장 → 사용자가 카테고리 지정 → 설명·정답 검토
→ 승인된 후보만 추가 CSV → 다음 재학습
```

끝까지 미분류인 거래는 학습에서 제외한다. 사용자가 지정했어도 설명이 `물품 구매`처럼
불충분하면 승인하지 않는다. 현재 재학습 코드는 준비된 승인 CSV를 읽는 부분만 구현했으며,
거래 저장·사용자 지정 수집·검토·CSV 내보내기는 후속 연결 작업이다.

최종 목표는 수입용·지출용 모델 각 하나이며 미분류 전용 모델을 추가하는 방식은 아니다.
각 모델의 판단 점수를 기준으로 추천을 보류하는 방식을 검토한다. 현재 API는 설명이 없는
지출을 미분류로 반환하며, 점수 기반 미분류 임계값은 미정·미구현이다.
임계값은 별도 검증자료로 확인하고 결정한다. 모델 점수가 실제 정답 확률을 보장하지 않는다.

## 직접 실행

가상환경 활성화 후 프로젝트 루트에서:

```cmd
python ml/scripts/retrain_expense.py
```

이미 ml 폴더에 있다면:

```cmd
python scripts/retrain_expense.py
```

처음 실행하면 추가 CSV를 넣을 폴더도 생성된다. 추가 CSV가 없어도 초기 자료로 실행 가능하다.
입력 내용이 이전 성공 실행과 같으면 학습을 생략한다. CSV를 지우면 다음 실행에서 해당 데이터가 빠지므로 누적 파일을 보존한다.
ID·설명 중복은 하나만 학습하며 정답 충돌, 필수값 누락, 미승인 행, 시험 자료 중복은 오류로 중단한다.
유사한 의미까지 자동 판별하지 않으므로 승인 시 시험자료와의 의미 중복도 검토한다.

결과 폴더에는 합쳐진 CSV와 고정 시험자료, 두 모델, test_report.json, test_predictions.csv,
입력 파일 해시·추가/중복 건수·완료/실패 상태가 남는다. 기존 자료와 모델을 덮어쓰지 않는다.
시험 자료를 반복 사용한 점수는 독립적인 최종 평가가 아니다. 점수를 보며 설정을 반복 조정하지 않는다.
새 모델은 자동 배포하지 않는다. 기존 평가 결과와 비교·검토 후 모델 교체를 별도 진행한다.

## 스케줄러에서 실행

Windows 작업 스케줄러 등 외부 스케줄러가 같은 명령을 실행하면 된다.
가상환경 활성화 스크립트 대신 가상환경 Python을 실행 프로그램으로 지정한다.

| 설정 | 값 (프로젝트 루트 기준) |
| --- | --- |
| 프로그램 | `ml/.venv/Scripts/python.exe`의 실제 위치 |
| 인수 | `ml/scripts/retrain_expense.py` |
| 시작 위치 | 프로젝트 루트의 실제 위치 |

스케줄러 설정에는 PC의 실제 경로가 필요하지만 소스에는 고정하지 않는다.
실행 주기는 아직 정하지 않았으므로 작업을 자동 등록하지 않았다.
동시 실행은 .retrain.lock으로 차단한다. 정상 실패 시 잠금은 해제한다.
강제 종료 후 잠금이 남았다면 실행 중인 학습 프로세스가 없는지 확인한 뒤 해당 잠금 파일만 지운다.
실패 종료 코드는 1이며, 완성된 새 CSV를 넣거나 오류를 수정한 뒤 재실행할 수 있다.
