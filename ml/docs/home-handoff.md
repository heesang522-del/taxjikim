## 유지할 기준

- 수입·지출 모델을 분리하고 지출부터 진행한다. 두 후보를 비교해 각 모델 하나를 선택한다.
- 입력은 description 하나, 정답은 category_code다. ID·날짜·금액·정답 코드를 특징에 넣지 않는다.
- v4 후보는 PENDING·training_ready=false다. needs_info.csv 10건과 review_cases.csv 8건은 학습 정답으로 사용하지 않는다.
- 모호한 원문에 없는 목적을 만들어 보충하지 않는다. 경계 사례는 정답 없이 보류한다.
- 자체 점검은 필수값·ID·정규화 중복·코드·상충 정답·재현성·기존 자료 보존이다. 실사용 정확도 검증이 아니다.
- v4에는 이전 대표 설명이 포함된다. 과거 평가 자료와 중복·유사 그룹을 확인하며, v4 전체로 학습한 뒤 기존 test로 평가하지 않는다.

## 실행과 다음 작업

프로젝트 최상위 PowerShell에서 실행한다.

```powershell
.\ml\.venv\Scripts\Activate.ps1
python ml/scripts/generate_dummy.py --expanded-draft
```

기존 결과가 있으면 중단한다. 검토본을 보존한 뒤 필요한 경우에만 --overwrite를 사용한다.
옵션 없는 생성은 v3용이다. v4 생성 후 기존 분할·학습 스크립트를 바로 실행하지 않는다.
생성 자료·모델은 Git 제외 대상이므로 각 PC에서 재현하거나 보존본을 별도로 준비한다.

1. v4 정답 후보·경계 사례를 설명과 한글 정답 표로 함께 검토한다.
2. v4용 유사 그룹·분할을 설계하고 과거 평가 자료와 중복을 점검한다.
3. 실행 명령을 안내한 뒤 학습·검증 결과를 사용자와 함께 확인한다.
4. 미분류 기준·최종 시험을 확인한 뒤 분류 API를 연결한다.
5. 세금계산 클릭 시 전체 거래와 사용자 지정 학습 후보를 별도 저장한다.
6. 후보 검토→수동 재학습→평가·교체가 안정된 뒤 스케줄러를 연결한다.

더미 생성 TJK-158, 기존 설계 TJK-126, 자동 분류·재학습 구현 상위 TJK-164다.
이 문서는 새 학습·커밋·push 실행 요청을 대신하지 않는다.
