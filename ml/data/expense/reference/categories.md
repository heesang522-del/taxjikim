# 지출 카테고리

학습 CSV의 `category_code`에 사용하는 정답 코드와 뜻이다.

| 코드 | 카테고리 | 포함 예시 |
| --- | --- | --- |
| `SOFTWARE_LICENSE` | 소프트웨어 | 편집 프로그램, 음원 라이선스, 스팀 게임 결제, 게임 내 결제 |
| `EQUIPMENT` | 하드웨어 | 카메라, 마이크, 스피커, SSD·HDD, 게임기 본체 |
| `TELECOMMUNICATION` | 통신비 | 휴대전화, 인터넷, 데이터·로밍 요금 |
| `TRANSPORT` | 교통비 | 택시, 버스, 기차, 항공·선박 운임, 주차요금 |
| `SUPPLIES_PROPS` | 소모품·소품 | 티슈, 테이프, 촬영 소품, 먹방용 음식·재료, 리뷰용 제품 |
| `SPACE_RENTAL` | 공간 대여 | 스튜디오, 녹음 부스, 촬영 출장 숙박 |
| `OUTSOURCING` | 외주비 | 편집, 번역, 디자인 등 외부 작업 의뢰 |
| `AD_PROMOTION` | 광고·홍보 | 채널·영상 홍보를 위한 광고 집행 |
| `OTHER` | 기타 | 용도는 알지만 위 범주에 속하지 않는 지출 |

리뷰용 제품도 전자기기는 `EQUIPMENT` 등 물품 성격에 맞춰 구분한다.
홍보 영상 제작을 편집자에게 맡긴 작업비는 `OUTSOURCING`, 광고를 게재한 비용은 `AD_PROMOTION`이다.

`UNCLASSIFIED`는 **미분류**다. 설명이 없거나 모델 판단을 보류한 결과이며, 학습 정답에 넣지 않는다.
