# 수입 카테고리

학습 CSV의 `category_code`에 사용하는 정답 코드와 뜻이다.

| 코드 | 카테고리 | 포함 예시 |
| --- | --- | --- |
| `YOUTUBE_SETTLEMENT` | 유튜브 플랫폼 정산 | 유튜브 정산, 유튜브 영상 광고 수익, 플랫폼 안의 후원 |
| `AD_SPONSORSHIP` | 광고·협찬 | 광고 협찬 정산, 브랜드 협찬 영상 제작비, 제휴 광고 콘텐츠 제작 대금, 제휴 링크 판매 수수료 |
| `EXTERNAL_SUPPORT` | 외부 후원 | 유튜브 밖의 후원 플랫폼 정산, 외부 후원 입금 |
| `OTHER` | 기타 | 영상 소스 판매 대금, 채널 굿즈 판매 수익, 영상 제작 강의료 |

유튜브 플랫폼에서 받는 광고 수익은 `YOUTUBE_SETTLEMENT`, 브랜드와의 광고·협찬 대금은 `AD_SPONSORSHIP`이다.
후원은 유튜브 플랫폼 안에서 받은 것인지, 밖에서 받은 것인지 구분한다.
`AD_SPONSORSHIP`은 광고로 받은 수입이며, 지출의 `AD_PROMOTION`(광고·홍보비)과 다르다.

`UNCLASSIFIED`는 **미분류**다. 설명이 없거나 모델 판단을 보류한 결과이며, 학습 정답에 넣지 않는다.

프로젝트 분류 기준상 광고·협찬·제휴로 받은 대금은 `AD_SPONSORSHIP`, 소스·굿즈 판매와 강의 수입은 `OTHER`로 구분한다.
`수익 입금`, `정산금`처럼 출처나 용도를 모르는 설명은 기타 정답으로 학습하지 않는다.
